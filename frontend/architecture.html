Components

Frontend

Vanilla HTML/CSS/JS. Product landing at index.html, Mission Control at dashboard.html, and shared operational workspace pages. SSE via EventSource API.

HTML5 CSS3 Vanilla JS SVG

FastAPI

Python ASGI backend. Serves REST API (/api/agent/run), SSE stream (/api/agent/stream), health check, and static frontend files.

FastAPI Uvicorn Pydantic

LangGraph

StateGraph: START → memory_recall → intent_analyzer → knowledge_retriever → conditional route → one of five agents → response → END. Router is an edge, not a graph node.

LangGraph 0.2+ TypedDict

Gemini 1.5 Flash

langchain-google-genai supports classification and response generation. If not configured or a call fails, deterministic routing and safe guidance are used.

Gemini Flash LangChain

SSE Streaming

Real-time streaming via Server-Sent Events. Each LangGraph node emits an event: node name, state snapshot, log message, route info.

EventSource app.stream()

State Management

AgentState TypedDict flows through every node. Each node receives full state and returns a partial dict of updates — immutable by design.

TypedDict Immutable
