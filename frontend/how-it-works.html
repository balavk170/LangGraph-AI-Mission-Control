LangGraph Explained

How LangGraph Works

A clear, beginner-friendly — yet technically accurate — guide to building AI agents with LangGraph.

01 · State

Shared Agent State

State is a TypedDict that flows through every node. Each node reads from it and writes updates back. It holds everything: intent, confidence, response.

class AgentState(TypedDict):
  input: str
  intent: str
  confidence: float
  response: str
02 · Nodes

Processing Units

Each node is a plain Python function. It receives the current state, does work (LLM call, logic, DB query), and returns a dict of updates.

def billing_node(state):
  return {"response": "...",
    "current_node": "BILLING"}
03 · Edges

Connection Paths

Edges define execution order. Static edges go to a fixed next node. Conditional edges call a function to decide the next node at runtime.

graph.add_edge("billing", "response")
graph.add_conditional_edges(
  "knowledge_retriever", decide_route)
04 · Router

Conditional Routing

The router is a Python function that reads the detected intent from state and returns a string — the name of the next node to execute.

def decide_route(state):
  if state["intent"] == "BILLING":
    return "billing"
05 · START / END

Entry & Exit

START is the special entry node every graph has. END signals termination. The final state at END is the result of the workflow.

graph.add_edge(START, "intent_analyzer")
graph.add_edge("response", END)
06 · Streaming

Real-Time Output

LangGraph supports streaming via app.stream(). Each chunk contains the output of a single node, enabling live UI updates as the agent executes.

for chunk in app.stream(state):
  for node, updates in chunk.items():
    yield updates
07 · Persistence

Memory & Checkpointing

This app persists successful turns in SQLite and loads the current session through its MEMORY node. It does not configure a LangGraph checkpointer.

memory = get_memory(session_id)
state["memory_context"] = memory
08 · Human-in-the-Loop

Approval Gates

LangGraph supports interrupt-based approval, but this project has no approval gate or checkpoint-resume path configured.

graph.compile(
  interrupt_before=["billing"]
)
09 · Compile & Run

Execution Engine

Once the graph is defined, call .compile() to get a runnable app. Then call .invoke() or .stream() with an initial state to execute it.

app = graph.compile()
result = app.invoke({"input": "..."})
10 · Why LangGraph?

Graph-Based Agents

Unlike simple LLM chains, LangGraph gives you explicit control: which node runs next, what state is shared, when to loop, and when to stop — all with Python functions.

# Control flow is explicit
# State is typed
# Streaming is built-in
